A bounded reader now extracts only a coarse mapping type and permissions for the faulting address, checks PID against `ApplicationExitInfo`, handles ARM64 top-byte tags and declines missing, malformed or oversized data. It never reports mapping paths or memory bytes. The parser runs during background last-session collection for native API 31+ exit records, and output is included in the existing exit/report.
