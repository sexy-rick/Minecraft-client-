# Handoff
## 1. Goal
Resolve the reported game bytecode lookup failure while preserving the installed runtime and improve diagnostics for Minecraft 1.26.66.xx in-process hosting without claiming unverified causes, altering integrity checks or falling back to external Minecraft.
## 2. Current state
Live log has a Copy diagnostic action with device/version details, recent focused events, last Android exit and last Java crash, with a privacy warning. Native dependency plans and pre-load attempts are logged; retained markers are evidence, not proof of a cause. The user reported SIGABRT while PairIP attempted to load a missing VM bytecode asset from the wrong APK; the wrong-APK explanation is an inference based on classpath order and a nearby Minecraft runtime, not an observation of their exact APK. The loader now attempts to bind the original Minecraft base APK before engine load, and fails clearly if that runtime layout is unsupported. Actual device compatibility remains unverified. Never patch integrity dependencies, fake exports or silently launch external Minecraft.
